# 術語對照與譯名政策

> 定案日期:2026-08-07
> 機器可讀的表在 [`internal/i18n/names.go`](../../internal/i18n/names.go);
> 本檔說明**為什麼**這樣譯,以及哪些是抄來的、哪些是本專案自己決定的。

---

## 1. 權威順序

1. 1990 年代《軟體世界》雜誌「說明書補完計劃」的《創世紀第 V 代》中文說明書
2. **姊妹專案 u6-cht / u4-cht / u1-cht 的既有譯名**
3. 現代直觀

第 2 條是**硬規則**(使用者指示 2026-08-07:「名稱請跟 u6-cht 對齊」)。
系列共通名不另立新譯,**即使本專案先寫了別的**。

|---|---|---|

| Jhelom | 哲倫 | **傑隆** |

改完之後譯名一律搬到 `internal/i18n`,資料表不再存中文 —— 分散的譯名一定會漂移。

## 5. 本專案自己決定的

U5 獨有、u6 沒有的名詞。原則是**音譯從系列的用字習慣,意譯優先於音譯**:

- **八座地牢**照字面意思譯,不音譯:欺瞞 / 輕蔑 / 毀滅 / 謬誤 / 貪婪 / 羞恥 / 末日。
  唯一例外是 **Hythloth → 海斯洛斯** —— 那是 Thomas More《烏托邦》裡
  Hythloday 的變體,不是英文常用詞,音譯。
- **四座燈塔**意譯:破霧塔 / 暴風鴉塔 / 灰港塔 / 導浪塔。
- **頭銜照譯不音譯**:Lord 領主、Lady 夫人、Sir 爵士、Judge 法官、Captain 船長、
  Squire 侍從、Monsieur 先生。
- **綽號型的名字照意思譯**:`Hardluck` → 苦命漢、`Sir Adam the Torch` → 火炬亞當爵士、
  `Lord Stuart the Hungry` → 飢餓的史都華領主。
- **日式名用漢字**:Fumiko 文子、Kaiko 佳子、Tetsuo 哲雄、Tomoka 智香、Toshi 俊、
  Yasuda 安田。U5 有一小群日式名的 NPC,音譯成片假名式的中文會很怪。
- **`Saduj` 譯成薩杜傑**,不點破。那是 `Judas` 倒過來拼 —— 原文自己就把伏筆藏在字母裡,
  中文如果譯成「猶大」等於替玩家把謎底揭了。

## 6. [HARD] 什麼不能翻

**會拿去跟玩家輸入比對的字串,原文一律維持英文。** 玩家在遊戲裡打不出中文。

| 類別 | 例子 | 處理 |
|---|---|---|
| 咒語名 | `An Nox`、`Vas Mani` | 顯示可用「中文(English)」,比對用英文 |
| 對話關鍵字 | `name`、`job`、`join`、`bye` | 完全不動 |
| 是非題 | `Yes` / `No` | 完全不動 |
| NPC 名字 | 玩家可以打 NPC 的名字問別人 | **顯示中文,比對用英文原文** |
| 符文 | `RUNES.CH` 的符文輸入 | 另一條路徑,單獨盤 |

這是 u4-cht 踩過的坑:把 canonical 值換成中文之後,玩家永遠通不過那個關卡。

## 7. 覆蓋率

`tools/npcnames` 會列出四個 `.TLK` 檔裡所有 NPC 名字並標出翻了沒:

```
tools/dev.sh go run ./tools/npcnames
# 135 個不重複的 NPC 名,已翻 134
```

沒翻的那一個是 `....`(原版資料裡的佔位字串,不是人名)。

## 8. 新增譯名的流程

1. 先查 `~/u3-cht/u6-cht/dumps/glossary.json` 與 `distilled_manual.md`。有就抄,別重譯。
2. 沒有再查 u4-cht 的 `dumps/*_bilingual.json`。
3. 都沒有才自己譯,並在 `names.go` 的那一行寫上理由。
4. 系列共通名(跨代出現的人、地、物)加進 `names_test.go` 的 `TestSeriesNamesMatchU6`,
   讓它漂掉就紅。
