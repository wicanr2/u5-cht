## 1. 角色紀錄 32 B 的後半

拿 `INIT.GAM` 的十六名角色橫向對照(每一欄的值域 + 每個人的定位):

| 位移 | 欄位 | 值域 | 佐證 |
|---|---|---|---|
| 0x17 | 留在旅店的天數 | 0xFF 或 0..25 | 日期進位那段對 16 名角色跑 `byte_3DDCB[i*32]` |
| 0x18 | 傷害減免 | 全員 7 | 傷害函式讀 `byte_3DDCC[角色*32]` |
| 0x19 | 頭盔 | 0..3 / 0xFF | 名字表 0..3 是 Leather Helm…Spiked Helm |
| 0x1A | 護甲 | 9..15 | 名字表 9..15 是 Cloth Armour… |
| 0x1B | 右手 | 16..41 | 名字表 16..41 是武器 |
| 0x1C | 左手 | 4..8 或 16..41 | **盾或第二把武器** |
| 0x1D | 戒指 | 42..44 | Ring of Invisibility / Protection / Regeneration |
| 0x1E | 頸飾 | 45..47 | Amulet of Turning / Spiked Collar / Ankh |
| 0x1F | 留在旅店的標記 | 隊員 0x00、其餘 0xFF | 入隊時 `sub_1BB5C` 寫 `byte_3DDD3[i*32]` = 0 |

### 每個人的配備都符合定位 —— 這是解對了的旁證

```
聖者      鎖甲頭巾 + 鎖甲 + 長劍 + 安卡(0x1E = 0x2F)
Shamino   短劍 + 小盾
Iolo      **雙手各一把武器**(0x1B = 20、0x1C = 23)  ← 弓手
Mariah    無頭盔 + 布甲 + 匕首                        ← 法師
Geoffrey  釘盔 + 鱗甲 + 釘頭錘 + 釘盾 + 釘項圈        ← 戰士
```

Iolo 那一行決定了 0x1C **不能叫 shield**:它收得下武器。所以引擎那邊叫「副手」。

### 0x1F 的旁證

`SAVED.GAM` 的 `PartySize` 是 3,而 0x1F == 0x00 的**正好是前三名**,
其餘十三名都是 0xFF。兩個獨立的地方一致(`rulebook/62`)。

## 2. Ready(R)與 Wear(W)

原版分成兩個鍵,做的是同一件事:從背包拿一件、把身上原本那件放回背包。
差別只在**哪些欄位收得下**:

```
R  武器 16..41 → 右手 / 左手       盾 4..8 → 左手
W  頭盔 0..3 → 頭   護甲 9..15 → 身   戒指 42..44 → 指   頸飾 45..47 → 頸
```

### 兩條容易漏的

- ⚠ **換下來的要放回背包。** 少了這一步,玩家換一次裝備就永久失去原本那件 ——
  而症狀要等到很久以後翻背包才會發現,那時已經無法回推是哪一次吃掉的。
- ⚠ **右手滿了就往左手放。** 一律換掉右手的話玩家永遠裝不上第二把武器,
  而那是吟遊詩人的打法(Iolo 開局就是雙持)。

## 3. 引擎對應

| 原版 | 引擎 |

| 0x19..0x1E | `u5data.CharHelm` … `CharAmulet`(既有) |
