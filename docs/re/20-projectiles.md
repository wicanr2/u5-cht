## 1. 擋箭的表:`byte_60018`(DOS `0x6A24`)

```asm
mov   eax, [ebp+arg_4]
shl   eax, 5
add   eax, [ebp+arg_0]
movzx edi, byte_3F6E4[eax]      ; 視窗緩衝的那一格,stride 32
mov   eax, edi
sar   eax, 3
movzx eax, byte_60018[eax]
mov   ecx, edi
and   ecx, 7
mov   edx, 80h
sar   edx, cl
test  eax, edx
setnz al                         ; ★ bit = 1 → 回 1
```

⚠ **極性與行走那兩張相反。** 行走(`byte_5FF6C`)與 NPC(`byte_54524`)
都是 **bit = 1 代表擋住**;這一張是 **bit = 1 代表飛得過去**。
抄錯的話箭會變成只能穿牆、不能穿空地 —— 而畫面上只看得到「射不到」,
不會有任何東西報錯。

這張只有 **32 B(256 個 tile)**,不像行走那兩張是 64 B(512 個)。
世界地圖與戰場的格子值域本來就是 0..255。

### 用兩張表的差集驗它

46 個 tile 擋箭。其中 **39 個同時也擋行走**(牆、樹、山、屋)——
這是預期的。剩下 7 個 **擋箭卻不擋走路**:

```
0x12 / 0x13  騎著的馬
0x14 / 0x15  魔毯
0x19 / 0x1B  地上的魔毯
0x3E         (未命名)
```

全部是載具與坐騎:擋在中間的馬會把箭吃掉,但你可以走過去上馬。
反過來,**水(1..3)完全不擋箭**,而水是擋行走的。

兩張表的差集正好說得通 —— 這比逐格核對 256 個值可靠得多,
而且是一個位移偏掉就會垮的性質。

## 2. 飛行本身

`sub_20CB4(x1, y1, x2, y2, 種類)`:

1. `sub_2055C` 在 **×16 的像素空間**拉 Bresenham(每格再 +16 對到格心)。
   格子層級的結果與直接在格子上跑 Bresenham 一致 —— 差別只在動畫的平滑度。
2. 沿線一步一步走,每一步 `sub_2BC34` 查那一格擋不擋;**擋住就停在那裡**。
3. 步長 `var_14` 是 13 / 6 / 8 —— 依場合(地牢 6、種類 7 用 8)不同,
   那是動畫的取樣間隔,不影響落點。

`sub_1FE54` 在外面包一層:**沒命中時把終點換成目標旁邊隨機一格**
(`sub_1FDE8`)。所以失手的箭不會憑空消失,它會偏掉繼續飛。

⇒ **會誤傷自己人。** 站在射線上的隊友會替敵人擋箭。這是原版行為
(`sub_1FE54` 回傳的是**實際打到的那一個**,不是原本瞄的那一個),
不是我加的難度。

## 3. 四種風(`sub_1AEB4`)

In Zu(睡眠)、In Nox Hur(毒)、In Flam Hur(火)、In Vas Grav Corp(能量)
共用一支函式:

```
問方向(sub_1CC50)
sub_1AC20 算出一串格子
對那串格子上的每個單位:
    已經處理過(unit[+5] & 0x80)/ 死的(0x20)/ 空槽 → 跳過
    unit[+5] |= 0x80                      ← 同一發不會打到同一個人兩次
    依種類:
      1 In Zu       抗性判定 → 睡著
      2 In Nox Hur  擲 1..30 vs 該單位的防禦,擲輸才下毒
      3 In Flam Hur 傷害 random(0, 30)
      4 In Vas Grav Corp  抗性判定 → …
```

⚠ **範圍的形狀還沒逆完**。`sub_1AC20` 吃一個每個咒語各自不同的參數
(`word_3EF44` / `word_3EF42` / `word_3EF3C` / `off_3EF3E+2`),看起來是寬度。
引擎先用「從施法者往那個方向的一條直線,直到邊緣或被地形擋住」——
**射線本身照原版的投射物規則走**,只有寬度是近似,程式碼與這裡都標明了。

## 4. 這一輪解開的連鎖

投射物是好幾個東西共同的前置,一次接上四樣:

| 先前卡住的 | 現在 |
|---|---|
| 敵人的遠程攻擊「打到誰」是隨機挑鄰格 | 照射線走,路上第一個單位吃下 |
| 玩家的弓與弩沒有用處 | `CombatAttack` 依 `ItemRange` 射出去 |
| 四種風完全沒實作 | 掃過一條線,每人各作用一次 |
| 攻擊法術只能打相鄰 | 走同一條射線 |

咒語效果數:26 → **30**。
