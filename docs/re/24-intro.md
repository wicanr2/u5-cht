# 開場動畫:21 頁的頁表

> 輸入檔:`WORRIORS.EXP`(FM Towns)、`STORY.DAT`、`STORY1-6.16`
> 日期:2026-08-07

---

## 1. `sub_584B` 是整段開場

主迴圈是 `cmp edi, 15h; jge …` —— **21 頁**。每一頁從六張並列表取參數:

| 表 | 內容 |
|---|---|
| `byte_54280[頁]` | 用哪一個 `STORY*.16`(0..5) |
| `byte_54268[頁]` | 形狀編號 |
| `byte_542C8[頁]` | 頁的種類 |
| `dword_541B4[頁]` | 這一頁的文字在 `STORY.DAT` 裡的**檔案位移** |
| `byte_54298` / `byte_542B0` | 擺放座標(FM Towns 640×480) |

種類的作用:

```
0        只畫一張圖
1 / 2    多一段動畫(nullsub_11)
3        ★ 文字**不從 STORY.DAT 讀**,見 §3
>= 4     多畫一張:形狀 = 種類 × 2 − 5,位置 (x, y + 0x37)
```

## 2. ★ 兩件讓這張表可以直接用的事

**(a) 插圖檔名是 DOS 的。** `off_41BE8` 存的是 `STORY1.16`…`STORY6.16` ——
FM Towns 把遊戲中的美術換成 `.PNL` / `.TIF`,**唯獨開場插圖沿用 DOS 那六個檔**。
所以「哪一頁配哪一張圖」不是 FM Towns 專屬的,可以照搬。

**(b) 文字位移全部落在記錄邊界上。** 表裡 20 個非零位移

```
0, 273, 971, 1424, 2051, 2756, 3437, 3619, 4022, 4467,
4906, 5310, 5678, 6443, 7066, 7803, 8562, 9291, 10112, 10903
```

與 `STORY.DAT` 用 NUL 切出來的記錄起點**一個不差**。兩份獨立資料對上,
所以「頁 → 記錄」這條對應是量出來的,不是猜的。

⇒ 頁 0..5 → 記錄 0..5;**頁 6 是特例**;頁 7..20 → 記錄 6..19。

## 3. ⚠ 第 6 頁的位移是 0,那不是「指回第一筆」

它的種類是 3,走另一條路 —— 文字**寫死在執行檔裡的兩句**:

```
Instantly, a shimmering blue door springs up!
With heart beating rapidly, you step into it.
```

照抄位移表會把第 6 頁的文字弄成第 0 頁的重播,而畫面上完全看不出異常
(那一頁本來就有圖有字)。**位移 0 在一張「位移表」裡看起來太正常了** ——
要對照種類欄才發現它是特例。

譯文因此另開一組 key(`i18n` 的 `INTRO#0` / `INTRO#1`),不放在
`STORY.DAT#*` 裡面。

## 4. 沒有沿用的部分

**擺放座標。** `byte_54298` / `byte_542B0` 與文字框的四張表
(`byte_54208` / `byte_54220` / `byte_54238` / `byte_54250`)都是 FM Towns
640×480 的版面。DOS 的座標在 `INTRO.OVL` 裡,**還沒讀**。

所以引擎自己排版:插圖 2× 靠上置中,下方一塊實心黑底放文字 ——
形狀上與原版一致(原版也是把文字疊在插圖上的方框裡),精確位置不是。
第二張圖的 `y + 0x37` 這個**相對**位移倒是照抄了。

## 5. 引擎的實作

- `u5data.IntroPages` —— 21 頁的表(`Story` / `Shape` / `Shape2` / `Record`)
- `game.Intro` —— 翻頁狀態機,`PromptIntro`,任意鍵翻頁、ESC 跳過
- ⚠ **中文比英文佔行**,所以文字比框高時**先把同一頁捲完才翻頁** ——
  直接翻頁的話玩家會看不到後半段,而且不會知道自己漏了
- 新遊戲自動播(原版也是),有進度就跳過;`-intro` 強制重播

驗收(`internal/game/intro_test.go`):20 筆記錄每一筆都恰好被一頁用到、
記錄序號遞增、每一頁指到的插圖真的存在、每一頁都拿得到中文
(含寫死那一頁)、一路按下去會走完 21 頁而不是卡在某頁的捲動裡。
