# 升級:「奇異而熟悉的老人」

> 輸入檔:`WORRIORS.EXP`(FM Towns)
> 日期:2026-08-07

U5 沒有「打完怪就跳等」這回事。升級是一個**事件**:紮營休息醒來時
有 **1/4 機率**出現一位老人,把全隊照經驗值重算等級,然後消失。

```
sub_165C8   紮營 / 休息
  └ random(0,99) < 25  且 !(arg_0 & 0x82)
      └ sub_10C34   ★「An apparition!」
```

---

## 1. 等級門檻是「100 起跳、之後翻倍」

```asm
mov  ebx, 1
movsx eax, word_3DDC8[eax]   ; 經驗值(紀錄 0x14)
cdq
mov  ecx, 64h                ; 100
idiv ecx
xchg eax, esi
loc:
and  esi, esi
jle  short done
inc  ebx                     ; 等級 +1
sar  esi, 1                  ; 右移一位
jmp  short loc
```

`等級 = 1 + (經驗值 / 100 右移到 0 需要幾次)`,也就是門檻:

| 等級 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 經驗值 | 0 | 100 | 200 | 400 | 800 | 1600 | 3200 | 6400 |

經驗值上限是 9999(`sub_2BBDC` 的第三個參數),算出來正好 **8 級** ——
而 8 也正好是最高的咒語圈數。兩者是同一個數字,不是巧合:
第 8 圈的咒語要 8 級才發得動。

## 2. 升級做三件事

```asm
mov  byte_3DDCA[eax], dl     ; 等級
lea  edx, [ebx+ebx*4]        ; ×5
lea  edx, [edx+edx*2]        ; ×15
add  edx, edx                ; ×30
mov  word_3DDC6[eax], dx     ; 生命上限
mov  word_3DDC4[eax], dx     ; 目前生命 —— 一併補滿
```

1. **生命上限 = 目前生命 = 等級 × 30**。所以 8 級是 240。
2. **隨機一項三圍 +1**,上限 30(`sub_2BBB8(ptr, 1, 0x1E)`),
   分別印「stronger!」「quicker!」「wiser!」。
3. **魔力照職業重算**:

```
'A' 聖者 / 'M' 法師 → 魔力 = 智力
'B' 吟遊詩人        → 魔力 = 智力 / 2
其餘('F' 戰士)     → 不動(所以永遠是 0)
```

⚠ **等級沒變就整段跳過**(`cmp edx, ebx; jz loc_10ECE`)—— 連魔力都不重算。
所以反覆遇到老人不會一直長三圍。這一條寫漏的話,玩家只要一直紮營
就能把三圍推到 30,而且不會有任何測試變紅。
