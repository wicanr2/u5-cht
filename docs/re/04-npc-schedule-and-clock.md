# NPC、排程與時鐘

> 來源:FM Towns `WORRIORS.EXP`。相關函式 `sub_8858`(載入)、`sub_9C7C`(排程 slot)、
> `sub_9358`(位置比對)、`sub_8924`(每回合更新)、`sub_B98`(嚇跑平民)、
> `sub_29304`(時間推進)、`sub_1B52C`(對話分派)。

## 1. `.NPC` 檔格式 ✅

`sub_8858` 的載入邏輯:

```asm
byte_3E0A3--                     ; 地點編號改成 0-based
esi = byte_3E0A3 >> 3            ; 檔案 = {TOWNE,DWELLING,CASTLE,KEEP}.NPC[(編號-1)/8]
edx = byte_3E0A3 - esi*8         ; 檔內第幾個地點(0..7)
edi = (edx + edx*8) << 6         ; = edx * 576   ← 每個地點 576 B

sub_2C740(file, edi,       0x200, byte_3E570)   ; 512 B  32 × 16 B 排程
sub_2C740(file, edi+0x200, 0x20,  byte_3EDB0)   ;  32 B  每個 NPC 的生物編號
sub_2C740(file, edi+0x220, 0x20,  區域緩衝)      ;  32 B  每個 NPC 的對話號碼
for i in 0..31: word_3E77A[i*16] = 區域緩衝[i]   ; 對話號碼搬進執行期記錄
```

8 × 576 = 4,608 B = 檔案大小 ✓

**0 號槽是隊伍自己**:`sub_8924` 的更新迴圈從 `esi = 1` 起跑。檔案裡 0 號槽的內容
不是正常記錄(多數地點是 0,月光城與不列顛城留著 0x1C,還有一個是 0x29)—— 殘值,略過。

### 生物編號 → tile

算繪前要 **加 256**(原版就是 `movzx eax, al; add eax, 100h` 之後才呼叫畫 tile)。
人物圖都在 tileset 後半,而且以四張(四個朝向)為一組,所以人物的編號都是 4 的倍數。

| 編號範圍 | 內容 |
|---|---|
| < 0x40 | 物件與動物(tile 256–319 那一列:箱子、藥水、馬…),單張,不成組 |
| 0x40–0x73 | **人**(`sub_B98` 判「可以被嚇跑的平民」用的就是這個範圍),4 的倍數 |
| ≥ 0x74 | 怪物(STONEGATE 有一批) |

驗收:編號 0x70 → tile 368,算繪出來是持戟的鎧甲士兵,正對應 `sub_1B52C` 那句
"The guard offers no response!"。

## 2. 排程:16 B 記錄 ✅

| 位移 | 內容 |
|---|---|
| 0–2 | 三個 slot 的行為型別 |
| 3–5 | 三個 slot 的場景 X |
| 6–8 | 三個 slot 的場景 Y |
| 9–11 | 三個 slot 的樓層 |
| 12–15 | **四個**時刻 |

欄位位置由 `sub_9358` 證實(`rec[slot+3]` / `rec[slot+6]` / `rec[slot+9]`,slot ∈ 0..2)。

### 四個時刻但只有三個位置

`sub_9C7C(npc, hour)` 挑 slot:

```c
for (i = 0; i < 4; i++) d[i] = (unsigned char)(hour - rec[12 + i]);  // 8-bit 減法
slot = argmin(d[0], d[1], d[2]);
if (d[slot] > d[3]) slot = 1;        // ← 第四個時刻也指向 slot 1
```

取「最近剛過的那個時刻」。8-bit 減法讓 24 小時自然環繞,不必特判跨午夜。
最後那一行就是「四個時刻三個位置」的答案:**NPC 一天會回到位置 1 兩次**。

實例(不列顛城 1 號,位置 (5,18)F1 / (4,19)F0 / (2,5)F0,時刻 17/6/11/13):

```
00:00 slot0 二樓(睡覺) → 06:00 slot1 上工 → 11:00 slot2 外出
     → 13:00 slot1 回崗位 → 17:00 slot0 上樓就寢
```

少了那一行,NPC 下午會停在錯的位置。

## 3. 對話號碼的分派 ✅

`sub_1B52C` 讀執行期記錄的 +0x0A(就是第三段載入的值):

| 值 | 行為 |
|---|---|
| 0 | "No response!"(衛兵與雜役) |
| 1–0x7F | 查 `.TLK`(**值就是索引表裡的 id**,線性搜尋,不是陣列下標) |
| 0x80–0xFC | **商人**;低 7 位選店類,還要過營業時間(同樣用 `sub_9C7C`)才談得成 |
| 0xFD | "Don't hurt me! Please go away!" |
| 0xFE / 0xFF | 兩個特殊角色,各有專屬流程 |

`sub_B98` 會在平民被攻擊時把對話號碼改成 0xFD、三個 slot 的行為型別全設成 3(逃跑)。

## 4. 曆法與時間推進 ✅

`sub_29304(minutes)` 與它下游的進位:

```
byte_3E091 分   += minutes;  > 59 → 減 60 並進位
byte_3E08F 時   >= 24 → 減 24 並進位
byte_3E08E 日   > 28  → 設回 1 並進位
byte_3E08D 月   > 13  → 設回 1 並進位
word_3E084 年
```

**每月 28 天、每年 13 個月**。一般行動每回合 **1 分鐘**(`sub_1DC8` → `sub_29304(1)`);
紮營之類一次 20 分鐘。另有兩個狀態旗標:`byte_3E08A == 'T'` 時間完全停止、
`== 'Q'` 時間走一半。

場景載入時還會依時間切換:`if (hour < 5 || hour > 19) sub_324()` —— 夜間的燈光處理。
