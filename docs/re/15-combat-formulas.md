# 命中判定與戰鬥數值

> 輸入檔:`WORRIORS.EXP`(FM Towns)、DOS `DATA.OVL`
> 日期:2026-08-07
> **狀態:命中判定與四張數值表已解並實作;傷害值(`sub_B9A8`)還沒。**

攻擊的呼叫鏈:

```
sub_20134   一次攻擊
  ├ sub_1FA6C   瞄準(射程來自 byte_3F2F8[武器])
  ├ sub_1FD80   選中目標
  ├ sub_B484    ★ 命中判定
  │   └ sub_B398  取「攻擊」與「防禦」那兩項
  │       ├ sub_B35C   戰場單位的 +1 欄位
  │       └ sub_2F2BC  角色的裝備防禦加總
  └ sub_B9A8    傷害(還沒解)
```

---

## 1. 命中公式(`sub_B484`)

```
threshold = (目標的防禦 + 30 − 攻擊者的攻擊) / 2
roll      = max(1, random(0, 60) / 2)          ← sub_2B724,值域 1..30
命中 ⟺ roll >= threshold
```

防禦高 → 門檻高 → 難命中;攻擊高 → 門檻低 → 易命中。
門檻 ≤ 1 必中、≥ 31 必不中。

### ⚠ 亂數是閉區間

`sub_2B710(60)` → `sub_28E14(0, 60)`,而 `sub_28E14` 算範圍時是
`hi − lo` 之後 **`inc ecx`** —— 所以是 `[lo, hi]` **兩端都取得到**。

我第一版寫成半開區間,命中骰就變 1..29,擲不到 30 —— 最強的攻擊也會偶爾落空。
是 `TestAttackRollRange`(「值域兩端要涵蓋得到」)把它抓出來的。

### 參數的方向差點抄反

`sub_B484` 的呼叫是 `sub_B484(target, attacker, …, weapon)`,
第一個參數是**目標**不是攻擊者。看漏這一點,公式會變成
「攻擊高反而難命中」—— 讀起來還很像那麼回事。

判斷依據是 cdecl 的壓棧順序:`push esi(武器); push -byte_3E09F;
push edi(攻擊者); push ebx(目標); call sub_B484` → arg_0 = 目標。

### 「攻擊」取哪一項(`sub_B398`)

由**武器類別**決定:

| 武器類別 | 取哪一項 | 角色的來源 |
|---|---|---|
| 8(鈍器) | 力量 | 角色紀錄 0x0C |
| 其餘 | 裝備防禦加總 | `sub_2F2BC` |

怪物則走另一組欄位(`byte_3F050[生物*8]` 等,見下)。

另外三種武器(0x23、0x27、0x28)**必中**,連骰都不擲。

## 2. 四張數值表(全部在 DOS `DATA.OVL`)

| FM Towns | DOS | 內容 | 形狀 |
|---|---|---|---|
| `0x3F050` | `0x13CC` | 怪物屬性 | 48 筆 × 8 B |
| `0x3F2C8` | `0x1644` | 裝備防禦值 | 48 B |
| `0x3F2F8` | `0x1674` | 武器射程 | 48 B |
| `0x3F330` | `0x16AC` | 裝備類別 | 48 B |

### 怪物屬性:前三個欄位就是三圍

```
Mage    [10, 15, 20, …]   力量低、智力高
Bard    [15, 20, 10, …]   敏捷最高
Fighter [20, 15, 10, …]   力量高、智力低
Avatar  [25, 25, 25, …]   全能
```

`sub_B398` 印證了這件事:它取 `byte_3F050[生物*8]` 當「力量那一項」、
`byte_3F052[生物*8]` 當「智力那一項」,而角色走的是紀錄的 0x0C 與 0x0E
—— 正好是力量與智力。+3..+7 還沒對出語意。

### 裝備防禦值

頭盔 1/2/3/3、盾 2/3/3/5/0、護甲 1→10 遞增、武器幾乎都是 0
(只有 Main Gauche 是 1)、**防護戒指 2**、釘項圈 2。

整組同時對上,位移就不可能是湊巧。

### 武器射程(0 = 近戰)

```
匕首 3   投石索 4   火油 4   矛 5   投擲斧 4
弓 7     十字弓 8   魔法弓 15   魔法斧 15
```

正好是 U5 能扔能射的那幾樣。

### 裝備類別

只有一個值認得出來:**8 = 鈍器**(釘盔、釘盾、棍、釘頭錘、雙手錘)——
共同點是「用砸的」,而且 `sub_B398` 用它決定命中看不看力量。
其餘的值(2、3、7)還沒對出語意。
