# 八座聖壇與冥想

> 輸入檔:`WORRIORS.EXP`(FM Towns)、`MISCMSG.DAT`
> 主函式:`sub_1D394`(由 `sub_1DA10+23D` 呼叫)
> 日期:2026-08-07

---

## 1. 資料表

六張並列表,索引都是**八德的順序**(誠實 / 慈悲 / 勇氣 / 正義 / 犧牲 / 榮譽 / 靈性 / 謙遜):

| 表 | 內容 |
|---|---|
| `byte_411FC` / `byte_41204` | 聖壇的世界座標 X / Y |
| `off_411DC` | 真言 |
| `off_55FEC` | 美德名的**前四個字母** |
| `byte_5606C` / `byte_56074` / `byte_5607C` | 完成試煉加力量 / 敏捷 / 智力 |
| `dword_5602C` | 「去寶典學什麼」的文字位移 |

```
座標   (233,66) (128,92) (36,229) (73,11) (205,45) (81,207) (0,0) (231,216)
真言    Ahm      Mu       Ra       Beh     Cah      Summ     Om    Lum
前綴    hone     comp     valo     just    sacr     hono     spir  humi
力量    -        -        ✓        -       ✓        ✓        ✓     -
敏捷    -        ✓        -        ✓       ✓        -        ✓     -
智力    ✓        -        -        ✓       -        ✓        ✓     -
```

### 1.1 ★ `dword_5602C` 對得上 `MISCMSG.DAT`

值是 `[0, 27, 57, 95, 123, 159, 185, 214]`,而 `MISCMSG.DAT` 第 12..19 筆
**相對第 12 筆的位移完全相同**。所以「這座聖壇要汝去寶典學什麼」就是第
`12 + 美德` 筆(「不誠實之過!」「殘忍心腸之惡!」…)。兩份獨立資料對上,不是猜的。

### 1.2 ⚠ 靈性聖壇的座標是 (0,0)

那不是資料缺漏。`sub_1D394` 掃完八筆之後:

```asm
cmp edi, 8
jnz short loc_1D3D6
mov edi, 6          ; 掃不到 → 當成靈性
```

**站在任何一個不在座標表上的聖壇,一律當成靈性。** U5 的靈性聖壇在幽冥界,
靠這個 fallback 生效。

⚠ 引擎因此需要**兩支不同的函式**:`ShrineHere()` 照原版有 fallback(進來之後
才用),`OnShrineTile()` **沒有** fallback(入口判斷用)。混用的話玩家在任何一格
按 E 都會開始冥想。

### 1.3 ⚠ 為什麼比四個字母

`hone`(誠實)與 `hono`(榮譽)**只差第四個字母**。縮成三個字母兩座聖壇就分不出來。
測試 `TestVirtuePrefixesAreDistinguishable` 把這件事釘住。

## 2. 流程

```
1. 掃座標找出是哪一座(掃不到 → 靈性)
2. 「Upon what virtue dost thou meditate?」  讀最多 12 字元
      空字串 → 離開
      不含該座的四字母前綴 → var_4 = 0(但**不跳出**)
3. 問三次「Mantra:」                        讀最多 8 字元
      空字串 → 離開
      不符 → var_4 = 0(同樣不跳出)
4. var_4 == 0 → 印「Thine thoughts are unfocused.」結束
5. 全對:
   (a) byte_3E0DE 的第 n 位元 **沒**設 → 領試煉
         byte_3E0DC |= 1<<n
         印「聖壇開口,一項試煉就此降下!」+「去寶典學 <第 12+n 筆>」
   (b) 否則若 byte_3E0DC 的第 n 位元**有**設 → 領獎
         清掉該位元、業報 +3、依三張表加三圍(上限 30)
         **n == 7(謙遜)業報再 +3**
   (c) 其餘 → 獻金
         讀**一個** '0'..'9';n × 100 金 → 業報 +n(上限 99)
         金子不夠 → 印「Thou hast not that much gold!」再問
```

### 2.1 ⚠ 三次真言不是「三次機會」

原版把三次都問完才判(`var_4` 一路累積),**任何一次錯就整場失敗**。
寫成「三次機會」會讓聖壇好過太多。同理美德名打錯也不會當場跳出,
而是繼續問真言、最後一起判 —— 玩家不會馬上知道自己錯在哪。

### 2.2 ⚠ 兩組旗標缺一不可

`byte_3E0DE`(領過試煉)與 `byte_3E0DC`(試煉進行中)要一起看才分得出三個階段。
只留一個的話玩家可以站在原地無限重領三圍。

⚠ `sub_1D394` **只設 `byte_3E0DC`,從來不設 `byte_3E0DE`** ——
後者是讀寶典時才設的。所以第一次拜一定給試煉,而「去寶典」是必經的一步。
(寶典那段還沒逆,引擎目前在領試煉時把兩個位元一起設,
效果是「拜兩次就拿得到獎」—— 這是**簡化**,已在程式碼裡標明。)

### 2.3 謙遜是唯一三圍全不加的

`byte_5606C[7]` / `byte_56074[7]` / `byte_5607C[7]` 都是 0,而
`cmp edi, 7` 那一段額外再加 3 點業報。**用雙倍業報換掉三圍** ——
八德裡只有這一座這樣。

### 2.4 獻金只讀一個按鍵

```asm
loc_1D5B5:
call sub_29EEC        ; 讀一個鍵
cmp ebx, 30h ; '0'
jl  short loc_1D5B5   ; 不是數字就繼續等
cmp ebx, 39h ; '9'
jg  short loc_1D5B5
```

所以**一次最多獻 9 重 = 900 金 = 9 點業報**。讀成多位數會讓玩家一口氣衝滿。
金額算式是 `n × 5 × 5 × 4`(原版拆成三個 `lea`)= `n × 100`。

## 3. 引擎的實作

- `u5data.Shrines` —— 八座的座標、真言、前綴、三圍獎賞
- `game.Shrine` —— 冥想的狀態機(`PromptShrine`),打字回答
- 世界地圖上按 **E** 站在那七座之一就開始冥想
- ⚠ **真言與美德名維持英文輸入**(`[HARD]`,見 `docs/manual/術語對照.md` §6)——
  玩家在遊戲裡打不出中文

## 4. 還沒做的

- 靈性聖壇在幽冥界的入口。
- 黑棘的審問(`MISCMSG#0..11`,同一批真言,譯文已備妥)。
