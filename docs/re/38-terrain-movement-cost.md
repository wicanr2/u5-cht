IDA 位址:`sub_2D0BC`(分級與扣款)、`sub_2E24`(一個世界回合)、`sub_29304`(推時鐘)

## 1. 分級(`sub_2D0BC`)

```
tile = 隊伍腳下那一格
switch tile:
    5                → 0 級
    0x1E, 0x1F       → 1 級
    default:
        if 4 <= tile < 0x10:
            tile < 9 → 1 級
            否則     → 2 級
        否則         → 0 級
```

| tile | 地形 | 級 |
|---|---|---|
| 4 | 沼澤 | 1 |
| **5** | **草地** | **0** ← 落在 4..15 裡卻是 0 級 |
| 6, 8 | 灌木 | 1 |
| 7 | 焦灼荒漠 | 1 |
| 9 | 樹林 | 2 |
| 10 | 熱帶林 | 2 |
| 11, 14, 15 | 丘陵 | 2 |
| 12 | 山 | 2 |
| 13 | 高峰 | 2 |
| 0x1E, 0x1F | 荒漠(另一組) | 1 |

⚠ **草地是這張表唯一的陷阱。** 它在「4 ≤ t < 0x10」的範圍內,原版卻把它挑出來
放在 switch 的第一條。寫成「4..8 是一級」就會讓平原走起來跟沼澤一樣慢 ——
而那在遊玩時只覺得「怪」,不會有人查得出來。

## 2. 代價是什麼

```
1 級:  v = sub_2E24(tile)                    ← 跑一個世界回合
       if v == 0 → "Slow progress!"
       sub_29304(2)                          ← 時鐘 +2 分

2 級:  v = sub_2E24(tile) + sub_2E24(tile)   ← 跑兩個世界回合
       if v == 0 → "Very slow!"
       sub_29304(4)                          ← 時鐘 +4 分
```

★ **那多出來的回合是完整的世界回合。** `sub_2E24` 會:

- 依載具跳過(見下)
- 擲一次遭遇(`sub_1F98` 給門檻,`random(1,30)` 低於門檻就 `sub_2218` 生怪)
- 走過 0x1F 個物件槽,讓每一隻怪移動 / 攻擊(`sub_25F0`)
- 再走一遍,把離隊伍超過 0x1F 格的怪清掉

所以在山裡走一步,附近的怪會走三步。**這才是粗糙地形真正的代價**,
「多幾分鐘」只是副作用。寫成「只加時間」會讓穿越山區變得毫無風險。

### 時間與回合數是分開算的

不是「每個額外回合 1 分鐘」:1 級是 1 個回合 + 2 分鐘、2 級是 2 個回合 + 4 分鐘。
兩者各自寫死。

### 訊息只在「什麼都沒發生」時印

`sub_2E24` 的回傳值是「這個回合有沒有出事」。2 級要**兩次相加**都是 0 才印
「Very slow!」。遇上怪物的那一步不會印慢 —— 玩家已經有別的事要煩。

## 3. 載具的免費回合(`sub_2E24` 開頭)

```asm
cmp     byte_3E08C, ... ; and 0FEh
cmp     eax, 12h        ; 馬
jz      short loc_2E65
cmp     eax, 14h        ; 魔毯
jnz     short loc_2E7C
loc_2E65:
xor     byte_4FDD7, 1   ; 每呼叫一次翻一次
cmp     byte_4FDD7, 0
jz      short loc_2E7C
sub     eax, eax        ; 這一次直接回 0,整個世界回合跳過
```

**騎馬或坐魔毯時,每隔一次世界回合就整個跳過。** 這是一個持久的切換位元
(`byte_4FDD7`),不是機率 —— 效果等於「怪物只有一半的行動機會」。

同樣的手法也用在 `byte_3E08A == 'Q'`(Rel Tym 加速)那條路上,
而 `'T'`(An Tym 停時)則是直接跳到函式結尾,連遭遇都不擲。

## 4. 引擎對應

| 原版 | 引擎 |
|---|---|
| `sub_2D0BC` 的分級 | `game.TerrainCost` |
| `sub_2D0BC` 的扣款 | `game.State.payTerrainCost` |
| `sub_2E24` 的閘門 | `game.State.extraWorldTurn` 的前三個 `if` |
| `sub_2E24` 的**本體** | ⬜ **未實作**(見下方 §5) |
| `sub_29304(n)` | `game.State.AdvanceTime(n)` |

⚠ **順序這一句已被 `docs/re/81` §4 更正。** 原本寫著「呼叫點在 `moveInWorld`:
`tick()` 之後、月門之前 —— 原版 `sub_2D174` 就是這個順序」。

實際上 `sub_2D174`(移動 + 地形代價)在 `sub_2D9D0` 裡是 **line 79899**,
而每回合的收尾(`sub_29304(2)` 起)在 **line 80013**。⇒ 原版是
**移動 + 地形代價 → 才是每回合的收尾**,也就是**地形代價在前**;
引擎目前反了。修正與其餘七條回合結構缺口一起處理(`docs/re/81` §5)。
