# 並排驗收:DOS 原版 ⇄ 重製版的對照點

> 用途:`CLAUDE.md §6.1` 的兩個驗收門檻之一 ——「對 reference(DOSBox 跑的原版)實測比對」。
> 這份檔定義**雙方都走得到**的對照點,以及每個點要記下哪些欄位,好讓兩邊的紀錄可以逐格對。
> 立案:2026-08-09

## 0. 為什麼兩邊可以直接對

**兩邊讀的是同一份 `SAVED.GAM`。** 原版的「Journey Onward」與重製版的 `u5dump scene`
都從 `gamedata/SAVED.GAM` 起跑,而那份存檔的狀態是:

```
139 年 4 月 5 日 08:35 ・ 尤洛小屋 第 0 層 (15,15) ・ 隊伍 3 人 ・ 業報 75 ・ 糧 63 ・ 金 150
Elwood  聖者   HP 60/60 ・ Shamino 戰士 HP 5/60 ・ Iolo 吟遊詩人 HP 90/90
```

⇒ 第一畫面就該一模一樣(除了語言與字型)。**任何欄位對不上都是一條 finding**,
而不是「兩邊本來就不同」。

畫布兩邊都是 **640×400**:原版是 EGA 320×200 經 `scaler=normal2x` 整數 2×,
重製版的邏輯畫布本來就是 640×400(`CLAUDE.md §3`)。⇒ 幾何可以直接並排。

## 1. 兩邊怎麼驅動

| | DOS 原版 | 重製版 |
|---|---|---|
| 工具 | `tools/dosbox_play.sh <輸出目錄> <步驟檔>` | `tools/dev.sh go run ./cmd/u5dump scene gamedata re_work/fmtowns/iso/U5_E <out.png> --script '<腳本>'` |
| 進遊戲 | 等 9 秒跑完開場 → **`KP_Enter`**(⚠ 不是 `Return`、不是 `space`、不是 `j`) | 自動(讀 `SAVED.GAM`) |
| 移動 | `Up` `Down` `Left` `Right` | `n` `s` `e` `w` |
| 交談 | `t` 然後方向鍵 | `Tn` / `Ts` / `Te` / `Tw` |
| 進入 / 攀爬 | `e` / `k` | `E` / `K` |
| 角色表 | `z` | ⬜ 驅動不到(headless 腳本沒有這個鍵) |
| 存檔 | `q` | ⬜ 驅動不到 |
| 每步一張圖 | 步驟檔一行一步,自動截圖 | ⚠ **每次都從頭跑**,所以第 N 個對照點要用**前 N 步的完整腳本**(累積前綴) |

**[HARD] 重製版不准用除錯旗標**:`--at` / `--scene` / `--box` / `--beam` 與腳本裡的 `!`
一律禁用。它們會把狀態直接擺到某一幕 —— 那正是 `CLAUDE.md §6.1`「debug hook 會遮住真 bug」
講的東西。要驗的是**玩家真的走得到的路徑**。

## 2. 每個對照點要記的欄位

畫面右欄兩邊都有這幾樣,逐項抄下來(照畫面上的字面值,不要換算、不要補齊):

1. **隊伍列**每一行的文字(名字 / 數字 / 後綴字母)
2. **糧食 `F:` 與金幣 `G:`**
3. **日期**(原版 `4-5-139`;重製版「139 年 4 月 5 日」)與**時間**
4. **風向**
5. **訊息列**的每一行
6. **地圖窗**:玩家在哪一格、周圍有什麼(床 / 桌 / 火盆 / 門 / 出口 / NPC 幾個)
7. 其餘畫面上有的東西(座標、地形碼、居民數、業報 …)—— **有就記,沒有也記「沒有」**

## 3. 對照點清單

| # | 標籤 | 動作 | 這一點在問什麼 |
|---|---|---|---|
| A1 | `journey` | 讀檔後的第一畫面 | **版面與所有欄位的初始值**。兩邊差最多的地方通常在這裡 |
| A2 | `south3` | 往南 3 步 | 走得動嗎?撞到東西嗎?時間推進多少? |
| A3 | `west3` | 接著往西 3 步 | 家具擋不擋路(床 / 桌 / 椅) |
| A4 | `talk` | 對小屋裡的居民交談,問 `name` | **先問方向**的流程、對話文字、名字 |
| A5 | `leave` | 走到小屋出口離開場景 | 出去之後落在世界地圖的哪一格 |
| A6 | `world-n5` | 大地圖往北 5 步 | 世界地圖地形、時間推進(每步幾分鐘) |
| A7 | `world-e5` | 接著往東 5 步 | 同上,另一個方向 |

⬜ **只有原版走得到的**(記下來當日後的基準,重製版這輪不比):
`z` 角色表、`q` 存檔、商店介面、地牢第一人稱。

## 4. 判讀紀律

- **一格一格抄,不要「看起來一樣」就打勾。** 兩邊的字型與語言不同,
  眼睛很容易把「數字不同」讀成「排版不同」。
- 抄下來之後才比。**先記錄、後判斷**,不要邊看邊下結論。
- 對不上的每一條寫成:`欄位 / 原版的值 / 重製版的值 / 這算不算 finding`。
  「算不算」要說理由 —— 語言不同不算,**數值不同、欄位少了、位置不同都算**。
- 走不到某個對照點就誠實記「受阻」+ 為什麼,**不要為了填滿表格改用除錯旗標**。
